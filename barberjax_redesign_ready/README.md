# BarberJax redesign

See on uus BarberJaxi ühe-leheline versioon.

## Väga oluline piltide kohta

Uus kujundus kasutab samu failinimesid, mida vana repo juba kasutas:

- `logo.png`
- `favicon.ico`
- `favicon.png`
- `apple-touch-icon.png`
- `images/hero-bg.png`
- `images/story.jpg`
- `images/story.webp`
- `images/g1.jpg`
- `images/g2.jpg`
- `images/g3.jpg`
- `images/g4.jpg`
- `images/g5.jpg`
- `images/g6.jpg`

Seega kõige lihtsam on:
1. jäta vana repo `images/` kaust alles;
2. asenda repo juures `index.html`, `styles.css` ja `app.js` selle ZIP-i failidega;
3. jäta logo ja faviconi failid alles.

Kui mõni pilt puudub, lisa see sama failinimega `images/` kausta.
