Kasutamine GitHub Pagesis:
1. Lae kogu selle kausta sisu oma GitHubi repo soovitud kausta või repo juurkausta.
2. Kui avaldad GitHub Pagesiga, vali Settings -> Pages -> Deploy from a branch.
3. Vali branch main ja sobiv kaust.
